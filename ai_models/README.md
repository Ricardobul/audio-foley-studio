# AI Foley Models Directory

This directory hosts the third-party neural audio repositories:

1. **Meta AudioCraft / AudioGen**:
   * Repository: [facebookresearch/audiocraft](https://github.com/facebookresearch/audiocraft)
   * Role: Local Text-to-SFX generation.
2. **FoleyCrafter**:
   * Repository: [open-mmlab/FoleyCrafter](https://github.com/open-mmlab/FoleyCrafter)
   * Role: Video-to-audio Foley synchronization.
3. **T-Foley**:
   * Repository: [YoonjinXD/T-foley](https://github.com/YoonjinXD/T-foley)
   * Role: Waveform-domain temporal-event-guided diffusion.

To automatically clone all models, run:
```bash
python scripts/install_ai_models.py
```
